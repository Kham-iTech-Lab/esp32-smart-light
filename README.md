# ESP32 เปิดปิดไฟในบ้านจากมือถือ 💡

เปิดหน้าเว็บในมือถือ กดปุ่มเปิด/ปิดไฟได้หลายดวง ไม่ต้องลงแอป และยังมีปุ่มที่ผนังไว้กดเองได้ถ้าเน็ตล่ม

จากคลิป **K iTech Review** (TikTok) · **Kham iTech Lab** (YouTube / Facebook)

## ⚠️ อ่านก่อน

ไฟบ้าน 220V **อันตรายถึงชีวิต**
- ตัดเบรกเกอร์ก่อนต่อสายทุกครั้ง
- เก็บจุดต่อทั้งหมดไว้ในกล่องพักสาย ห้ามบิดสายแล้วพันเทปทิ้งไว้
- ถ้าไม่มั่นใจเรื่องไฟฟ้า ใช้ปลั๊กอัจฉริยะสำเร็จรูป หรือให้ช่างไฟต่อฝั่ง 220V ให้

## ของที่ใช้

| ชิ้น | หมายเหตุ |
|---|---|
| บอร์ด ESP32 | รุ่นไหนก็ได้ |
| โมดูลรีเลย์ 1 หรือ 2 ช่อง | ต้องรับได้ 250VAC 10A |
| อะแดปเตอร์ 5V | เลี้ยงบอร์ดกับรีเลย์ |
| ปุ่มกด (ไม่ใส่ก็ได้) | ไว้กดที่ผนัง |
| กล่องพักสาย | เก็บรีเลย์กับจุดต่อ |

## ต่อสาย

**ฝั่งไฟต่ำ**

| อุปกรณ์ | ขา | ต่อเข้า |
|---|---|---|
| รีเลย์ | VCC | 5V / VIN |
| | GND | GND |
| | IN1 | GPIO 26 (ไฟดวงที่ 1) |
| | IN2 | GPIO 25 (ไฟดวงที่ 2) |
| ปุ่มที่ผนัง | ขาหนึ่ง | GPIO 27 |
| | อีกขา | GND |

**ฝั่ง 220V** — ตัดเฉพาะสายเส้นไฟ **L** ที่เข้าหลอด มาต่อที่ขา **COM** กับ **NO** ของรีเลย์ สาย N ไม่ต้องตัด

## ติดตั้ง

1. เปิด Arduino IDE ติดตั้งบอร์ด ESP32 (Boards Manager → esp32 by Espressif) ไม่ต้องลงไลบรารีเพิ่ม
2. เปิดไฟล์ `smart_light/smart_light.ino`
3. ใส่ `WIFI_SSID`, `WIFI_PASS`
4. แก้ชื่อไฟกับขาใน `lights[]` ใช้ดวงเดียวก็ลบบรรทัดที่สองออก มีมากกว่านี้ก็เพิ่มบรรทัดได้
5. อัปโหลด แล้วเปิด Serial Monitor ที่ 115200 ดู IP

## ใช้งาน

เปิด IP ที่ขึ้นใน Serial Monitor หรือ `http://light.local` ในมือถือ (ต่อ Wi-Fi บ้านเดียวกัน) กดปุ่มข้างชื่อไฟเพื่อเปิด/ปิด กด "เพิ่มไปยังหน้าจอหลัก" ในเบราว์เซอร์ จะได้เหมือนแอป

## ค่าที่ปรับได้

| ค่า | ค่าเริ่มต้น | ความหมาย |
|---|---|---|
| `RELAY_ACTIVE_LOW` | true | ถ้าไฟติดเองตอนเปิดเครื่อง เปลี่ยนเป็น `false` |
| `RESTORE_AFTER_POWER_CUT` | false | `true` = ไฟดับแล้วกลับมา ให้เปิดเหมือนเดิม / `false` = ปิดหมด |

## ปัญหาที่เจอบ่อย

- **เปิด light.local ไม่ได้**: มือถือ Android บางรุ่นไม่รองรับ .local ให้ใช้ IP แทน
- **ไฟติดเองตอนเปิดเครื่อง**: แก้ `RELAY_ACTIVE_LOW = false`
- **รีเลย์ดังแต่ไฟไม่ติด**: ต่อสายผิดขา ต้องเป็น COM กับ NO ไม่ใช่ NC
